# CLAUDE.md

Guidance for Claude (and Claude Code) when working in this repository.

## Git commits and pull requests

Do not add AI attribution or session trailers to commit messages or pull
request descriptions. Never append lines such as:

    Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>
    Claude-Session: https://claude.ai/code/session_...

and do not add a "Generated with Claude Code" footer or any session link.
Write the commit subject, body, and PR description only.
